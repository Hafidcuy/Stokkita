Tentang Aplikasi & S&K

Stokita v1.0 · Sistem Inventaris Barang.

Stokita dapat dipasang sebagai aplikasi di perangkat Anda agar terasa seperti aplikasi native (layar penuh, bisa dibuka tanpa browser).

Syarat & Ketentuan

Data Stokita tersimpan di cloud (Supabase) dan terikat pada akun Anda. Cadangan data sepenuhnya tanggung jawab pengguna. Stokita dipakai untuk pengelolaan inventaris internal dan bukan untuk keperluan ilegal apa pun.

Bantuan & Panduan

Penjelasan lengkap setiap fitur dan pengaturan.

Tema Tampilan

Pilih mode Terang (Light), Gelap (Dark), atau sesuaikan otomatis dengan pengaturan sistem perangkat Anda agar nyaman di mata.

Google Spreadsheet

Hubungkan sistem ke Google Spreadsheet Anda untuk sinkronisasi data inventaris (impor data atau kirim data transaksi). Memerlukan URL Web App Google Apps Script yang dikonfigurasi melalui repositori proyek.

Format Kode Barang

Tentukan awalan (prefix) otomatis untuk kode barang Anda (contoh: BRG menjadi BRG001, BRG002, dst). Jika dikosongkan, sistem akan mempertahankan kode barang yang sudah ada.

Batas Stok Menipis

Atur batas minimum jumlah stok. Jika jumlah stok barang sama atau kurang dari nilai ini, barang akan otomatis ditandai dengan label "Menipis" untuk memudahkan pemantauan restok.

Data & Cadangan

Ekspor seluruh data inventaris dan transaksi ke file JSON untuk cadangan pribadi. Fitur Impor memungkinkan Anda memulihkan data dari cadangan tersebut ke perangkat apa pun.

Manajemen Penyimpanan

Pantau penggunaan penyimpanan lokal dan bersihkan cache aplikasi jika aplikasi terasa lambat atau ada data yang tidak sinkron.
